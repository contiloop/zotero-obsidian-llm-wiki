# zotero-obsidian-llm-wiki

An Obsidian vault setup for economics writing: collect and highlight sources in Zotero, bring them into Obsidian with ZotLit, and let an AI grow a wiki from your drafts.

This repository holds the **setup only** (structure, AI rules, templates, settings). Content stays local.

- `Home.md` — goal, structure, flow, highlight colors
- `AGENTS.md` — AI working rules (`CLAUDE.md` loads it)
- `System/SETUP.md` — how to rebuild this setup on a new machine
- `System/ZotLit/` — ZotLit templates (color-grouped highlights, title-based file names)
- `System/Templates/Wiki.md` — wiki page template
